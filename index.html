用同一个“拿红杯子”案例，追踪信息在 VLM 的一次 forward 中如何进入动作。

C · 图像 / 语言M · 动作表示
01 / 观察联系

动作怎么联系观察？

分析什么
动作 query 在哪一层关注红杯，以及“红”“杯子”等指令词。
怎么实现
逐层画 M → C 的 attention；移动杯子或换目标，检查关注是否跟随。
记录指标
目标区域／指令词的注意力占比；按 token 数校正，避免大区域天然占优。
02 / 信息编码

动作表示编码了什么？

分析什么
先知道“拿哪个”，还是已知道“在哪里、怎么动”？
怎么实现
冻结模型，从每层 M 读出目标／属性、相对位置、示范动作；C 作语义参照。
记录指标
语义分类准确率、位置误差、动作误差；探针容量相同，在留出场景上比较。
03 / 动作影响

信息如何影响动作？

分析什么
换掉目标语义或空间信息，动作是否发生对应变化。
怎么实现
逐层换入“蓝杯子”或“杯子在右侧”的配对表示；与同层、同规模随机替换对照。
记录指标
向配对参考动作的偏移；关键层再测执行目标切换率与成功率。

逐层形成指标 · 提议，待实测

语义先形成，再在空间中落实为动作？

三条曲线定位形成层；一个层间差概括顺序。横轴是网络深度，不是执行时间。

指标：语义→动作层间差 Δ₈₀

Δ₈₀ = (动作形成层 − 语义形成层) / (总层数 − 1)

正值：语义更早可读出；接近 0：同步；负值：不支持该先后假设。
支持假设需要同时看到

语义 → 空间 → 动作依次形成，且语义干预能定向改变动作。

可读出、关注和相关性都不能单独证明信息传递或“思考”。
如何计算、准备数据与比较
固定配对数据

同场景换目标；同指令换位置。使用可配对的 benchmark 初态，按场景／episode 分开探针训练与测试，避免记住布局。

统一形成层定义

准确率增益＝模型−基线；误差改善＝基线−模型，再分别除以自身最大正增益。首次连续两层达到 80% 为形成层；同时检查 60%／90% 阈值。形成层须有高于基线的区间证据；无正增益或未达标时记 N/A。

标签与不确定性

语义／位置取仿真真值；动作取独立成功示范，不用模型自己的输出当真值。语义基线为标签频率，位置／动作基线为训练均值；按场景重采样给出区间。缺少动作示范时不计算 Δ₈₀。

同条件对照

QwenFAST 与 QwenRGT 使用同一批数据、同一探针容量与划分。三条原始指标并列报告，归一化曲线只比较形成顺序；随机替换匹配层、位置数量和扰动尺度。

证据边界图均为假设示意。Δ₈₀ 是本项目提出的诊断量，不是现成标准或能力总分；尚不能据此认定模型按“先理解、再行动”推理。
