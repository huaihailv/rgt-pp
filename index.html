01C / STATIC + RUNTIME SHIFTS

LIBERO-Pro 2.0

22 类静态扰动 + 20 类有效动态干预，覆盖六个维度。

训练 → 测试不额外适应时：已有 LIBERO 策略 → Pro 2.0 测试实例。若使用官方增强轨迹训练，需遵守其训练／测试划分并单独报告。

任务条件 · Condition

静态：目标／容器移位。动态：抓前目标移动、放前容器被占。

考查 · 重新定位与路径调整

环境 · Environment

静态：换实例、几何、干扰物、纹理。动态：遮挡物或障碍进入。

考查 · 物体理解与避障

观测 · Observation

静态：相机、噪声变化。动态：相机漂移、丢帧、遮挡或光照变化。

考查 · 观测变化下的反馈控制

执行 · Execution

静态：固定延迟。动态：命令丢失、旧动作块、抓空或掉落。

考查 · 时序鲁棒性与失败恢复

机器人状态 · Robot state

静态：初态／标定偏差。动态：执行中可恢复的关节位移。

考查 · 状态变化后的纠正

语言 · Language

静态：同义改写。动态：执行中重新表述或澄清原目标。

考查 · 在线理解；并非强制换目标

类别依据：官方干预清单 ↗ · 下列短例为中文释义／机制举例，不是新增的官方任务。

03 / 信息使用

这些信息决定动作吗？

分析什么
内部换成“蓝杯子”，动作是否随之转向蓝杯子。
怎么实现
输入不变，逐层换入配对“拿蓝杯子”的表示；对比随机替换，再验证执行目标。

证据边界 关注 ≠ 编码 ≠ 使用。三项共用配对场景与语义标签；图中均为示意，因果判断还需干预对照与执行验证。
