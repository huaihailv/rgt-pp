# RGT · Benchmark Atlas

QwenRGT 训练与评测展示网页：LIBERO-Plus、LIBERO-PRO、VLABench，四类泛化与三种机制分析。

静态网页入口：`index.html`。GitHub Pages 从 `main` 分支根目录发布。

机制热力图、曲线与因果干预分布为示意，不是实验结果。样例图片为官方演示静帧，训练任务参考不等于已核实的训练集 episode。

仓库仅包含网页与配图，不包含模型、训练日志、数据集或访问凭据。
